# Vedika Community

Public support, product feedback, and feature requests for [Vedika](https://vedika.io), an astrology intelligence product by **Xalen Technology Pvt Ltd**.

This repository intentionally contains **no Vedika production source code, infrastructure, credentials, customer data, or private operating material**. It is the public conversation layer for developers using Vedika.

## Use this repository for

- reproducible SDK and API integration problems;
- documentation corrections;
- feature requests and product feedback;
- questions whose answers can safely remain public.

[Open an issue](https://github.com/vedika-io/vedika-community/issues/new/choose) using the form that best matches your request.

## Do not post publicly

Never include:

- API keys, access tokens, passwords, signing material, or complete authorization headers;
- birth details, customer records, payment information, account identifiers, or private API responses;
- security vulnerabilities or abuse reports;
- billing, subscription, or account-recovery information.

For account and billing help, use [Vedika support](https://vedika.io/contact). For security issues, follow [SECURITY.md](SECURITY.md).

## Product boundary

- **Vedika** is the astrology intelligence API and uses `api.vedika.io`, Vedika SDKs, and `vk_…` keys.
- **XALEN Ephemeris** is the open-source astronomical engine used by Vedika.
- **Xalen** is the parent company's separate AI platform with its own API, SDKs, account, and key namespace.

Ownership by the same company does not make the Vedika and Xalen APIs interchangeable.

## Response and triage

Public reports are reviewed for reproducibility, impact, and product fit. An accepted issue is not a delivery-date commitment. Security, account, billing, and customer-specific cases are redirected to private support channels.
