# Contributing

This repository tracks public feedback and support. It does not mirror Vedika's private product source.

Before opening an issue:

1. Search existing open and closed issues.
2. Confirm the behavior against the current [documentation](https://vedika.io/docs).
3. Reproduce it with the latest applicable SDK release when practical.
4. Remove secrets, personal data, customer content, and private account information.
5. Choose the structured issue form that matches the request.

Documentation-only pull requests may be considered for files in this repository. Product implementation pull requests cannot be accepted here because the production source is not published in this repository.
