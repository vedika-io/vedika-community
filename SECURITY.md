# Security policy

Do not report suspected vulnerabilities in public issues or discussions.

Use [GitHub private vulnerability reporting](https://github.com/vedika-io/vedika-community/security/advisories/new) to provide:

- the affected public surface;
- reproduction steps;
- observed and potential impact;
- any safe supporting evidence;
- a contact address for coordinated follow-up.

Never include real customer data or production credentials. Use minimal synthetic examples and redact authorization material.

Account compromise, billing, abuse, and API-key rotation requests should go through [Vedika support](https://vedika.io/contact).
