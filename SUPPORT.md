# Support

## Public support

Use GitHub issues for reproducible developer-facing problems that are safe to discuss publicly:

- SDK behavior;
- documented API behavior;
- examples and integration guidance;
- documentation corrections;
- feature requests.

Include the SDK and version, runtime and version, affected documented operation, expected behavior, actual behavior, and the smallest safe reproduction.

## Private support

Use [Vedika support](https://vedika.io/contact) for:

- account access or recovery;
- subscriptions, billing, invoices, and credits;
- API-key rotation;
- requests containing customer or personal data;
- contractual or enterprise support.

Do not paste secrets or personal data into a public issue, even temporarily.

## Security

Do not open a public issue for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md).
